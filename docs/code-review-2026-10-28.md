## 本次修复

1. **内部库源码与运行版本可能不一致**：直接启动 Vite 会引用 electron-setup 的旧 dist。Vite 主进程与预加载配置现明确解析到该工作区库源码，避免窗口修复因漏构建内部库而失效。
2. **连续点击可能并发启动镜像**：原锁只覆盖 scrcpy 就绪等待，不覆盖服务准备和窗口登记。现在整个启动共用同一 Promise；准备过程中关闭桌面后不再创建镜像进程。
3. **原生桥接失败后的请求仍进入等待**：管道错误现在保存终止状态，立即拒绝未完成和后续请求；启动超时终止辅助进程；主动关闭时清理等待队列。
4. **焦点/遮挡轮询异步异常**：窗口可能在异步等待期间销毁；现在整个轮询有异常收尾，并在完整操作完成后释放防重入标记，避免定时回调重叠及未处理拒绝。
5. **退出清理不完整**：before-quit 显式释放剪贴板中继，取消待写剪贴板计时器和内容，避免依赖窗口退出顺序。

1. 将每窗口焦点与遮挡检查合并到共享调度器：目前应用约450ms、镜像约350ms轮询，窗口越多开销越大；需先测量再调整，避免焦点恢复变慢。
2. 拆分 desktop/embed.js 与 pages/desktop/App.vue 的连接、镜像、输入和窗口逻辑；优先共享镜像与应用状态模型，降低漏改镜像的概率。
